# dpc-words

このリポジトリは、日本の医療制度で使用される診断群分類（DPC）および関連するICD-10コードを含む、毎日更新されるCSVファイルを提供します。データは自動的にスクレイピング、処理され、このリポジトリにコミットされます。

## ライブデモ

最新のDPC/ICDコードリストを検索できるウェブベースのインターフェースが用意されています。診断名またはコードで検索可能です。

## データファイル

主なデータは使いやすいようにCSV形式で提供されています。

*   **[`icd.csv`](icd.csv)**
    最新のDPC関連ICDコードの完全なリストです。ほとんどの用途において、このファイルの使用を推奨します。

*   **[`icd_list.csv`](icd_list.csv)**
    生成されたすべてのICDコードリストの履歴インデックスです。公開日と、`data/`ディレクトリ内にある対応するバージョン付きCSVファイルをマッピングしています。

    *例:*
    ```csv
    url,date
    idc_2022-05-20.csv,2022-05-20
    idc_2022-07-21.csv,2022-07-21
    ...
    ```

履歴としての日付付きCSVファイルおよびダウンロードした元のExcel（`.xlsx`）ファイルはすべて、[`/data`](/data)ディレクトリにアーカイブされています。

### CSVスキーマ（`icd.csv`）

| ヘッダー | 説明 |
| --- | --- |
| `MDCコード` | 主要診断群（MDC）コード |
| `分類コード` | 分類コード |
| `DPCコード` | DPCコード |
| `ICDコード` | ICD-10コード |
| `ICD名称` | ICD名称（日本語） |
| `有効期間開始日` | 有効期間開始日 |
| `有効期間終了日` | 有効期間終了日 |

## 仕組み

GitHub Actionsのワークフローが毎日実行され、以下の手順を行います。
1.  厚生労働省の公式DPCページをスクレイピングし、最新の「電子点数表」Excelファイルを検索します。
2.  新しいExcelファイルが見つかった場合はダウンロードします。
3.  各Excelファイル内の「４）ＩＣＤ」シートを解析します。
4.  データをクレンジングし、日付付きのCSVファイル（例: `idc_YYYY-MM-DD.csv`）に変換します。
5.  `icd.csv`を最新バージョンのコピーに更新します。
6.  新規および更新されたファイルをリポジトリにコミットします。

## データソース

データは厚生労働省の公式公表資料から取得しています。

- [DPC電子点数表 - 厚生労働省](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000198757_00008.html)
